## **📌 Instalasi di Termux:**
```bash
apt-get update -y
apt-get upgrade -y
git clone https://github.com/Gopartner/ApkTool-Termux-CLI.git
cd $HOME
ls
cd Apktool-termux
chmod +x *
make
python app.py
crtl+t(tab baru) python operasi.py
```
