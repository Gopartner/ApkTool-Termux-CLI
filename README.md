## **📌 Instalasi di Termux:**
```bash
apt-get update -y
apt-get upgrade -y
git clone https://github.com/Gopartner/ApkTool-Termux-CLI.git
cd $HOME
ls
cd Apktool-Termux-CLI
chmod +x *
make
app.py (jalankan dengan make)
operasi.py (jalankan pada tab baru [ctrl+t])
```
## struktur project setelah install
```bash
~/ApkTool-Termux-CLI

├── apks
│   └── base.apk
├── app.py
```
